# LinkedIn CV Agent — Documentación para Codex

Aplicación web local para automatizar la descarga de CVs en PDF desde candidaturas de LinkedIn, leer respuestas de preselección, mapear preguntas a campos configurables y exportar los datos a CSV/Excel.

> Uso previsto: herramienta interna para una cuenta con acceso legítimo a las candidaturas de una vacante publicada.
